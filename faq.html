怎么玩
GoalRush 要花钱吗?+
不要。这是 play-money 预测玩法 —— 你不需要充值、不需要押任何本金、不需要绑卡、不需要 KYC。你「选一个结果」就完成预测,比赛结束自动结算。

EDS 是 Luffa 生态的 utility token,作为玩家奖励发放,不是「赔付」,不是赌博彩金。
预测什么时候锁定?+
开赛前 5 分钟。在此之前你可以随时修改预测。锁定后系统不再接受任何改动,确保结算公平。
命中能赢多少 EDS?+
命中基础 EDS = 比赛权重 × 排名乘数。
比赛权重:小组赛 1.0× / 淘汰赛 1.5× / 决赛 2.0×
排名乘数:全网 Top 10% 玩家 5× / 10-50% 1× / 后 50% 0.5×

单账号每日最多 200 EDS,每周 1000 EDS — 防作弊设计,任何人都不能靠数量碾压。
开群挑战是什么?+
在 Luffa IM 里建一个群组,邀请群友一起预测。每 5 位新群友进群 = 立即 500 EDS + 群主头像挂件。

群组人数 ≥ 10 → 进入群组周排行榜,Top 3 群组拿 5000 / 2500 / 1000 EDS 大奖。

反作弊:被邀请的群友必须独立设备 + 独立手机号,同 IP / 同设备不计入。
结算 & 数据可信度
比赛结果谁说了算?+
我们不说了算。系统从三个权威体育数据源拉取结果:
- SofaScore(主源 · 5 分钟内 final)
- API-Football(副源 · 5-10 分钟)
- ESPN(校验源 · 10-15 分钟,权威)

三方对账规则:三源一致 → 直接发放;2:1 多数 → 取多数 + 标记 review(仍发放);全不一致 → 延迟到次日 12:00 强制人工 review。
EDS 多久到账?+
结算后 5 分钟内。整个流程:比赛终场 → 5 分钟内三源拉取 → 5-10 分钟对账 → 10-15 分钟 EDS 入账 + SA 推送通知。

服务等级:正确率 ≥ 99.5% / 延迟均值 < 5 分钟(7 天观察期后)。
我赢了为什么没到账?+
最常见三种情况:
1. 三方对账冲突 → 状态会显示「review 中」,12-24 小时内运营复核。
2. 反作弊触发 → 同 IP / 多账号 / 高度异常预测,EDS 会暂停发放,人工 review。
3. 你还没下载 Luffa → 网页版预测保存在本地,要下载 Luffa App 才能同步到链上钱包真领。

4 小时内首响应、24 小时内闭环。

GoalRush 本身不是受 SFC 监管的金融产品(也不需要 — 它不是 prediction market)。 我们的 SFC 背书来自集团合规架构,不直接背书本产品。

是真的。KOL 的每条预测在开赛前 5 分钟系统级锁定,数据库不可修改。结算靠三源对账,KOL 本人无法影响。
